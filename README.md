# VideoImageOperation

面向巴西跨境电商团队的视频复刻工作台。中文网页，默认生成内容为巴西葡萄牙语（pt-BR）。第一版使用 FastAPI、SQLite 和 FFmpeg，支持局域网访问。

## 快速启动（Windows）

需要 Python 3.11 或以上版本。双击项目中的 **start.bat**，首次启动自动创建虚拟环境并安装固定版本依赖。FFmpeg 已随依赖提供，也可设置 `FFMPEG_PATH` 使用系统版本。

打开 **http://127.0.0.1:8000**。首次页面要求创建管理员：填写非空用户名、非空密码，以及服务窗口显示的初始化令牌。用户名支持中文、符号及单个字符，用户名和密码均无应用层长度上限。令牌也保存在本机 `data/setup.token`，初始化成功后删除。没有预设用户名或密码，没有公开注册入口。

启动脚本：

```powershell
.\start.ps1
```

已安装依赖时可直接启动：

```powershell
.\.venv\Scripts\python.exe -X utf8 run.py
```

服务默认监听 `0.0.0.0:8000`。同一局域网的电脑访问 `http://服务器的IPv4地址:8000`，例如 `http://192.168.1.20:8000`。`127.0.0.1` 只指向当前访问者自己的电脑。可通过 `ipconfig` 查看服务器地址；Windows 防火墙需允许该端口在私人网络中入站。项目不会自动修改防火墙。

复制 `.env.example` 为 `.env` 可更改端口、数据库、文件额度等。只运行 **一个进程**，不要启用 Uvicorn 多 worker 或 reload；后台任务与服务共享一个持久队列。关闭启动窗口会停止服务。云端/跨公网部署应在前面配置 HTTPS 反向代理，并设置 `VIO_SECURE_COOKIE=1`。

## 首次配置与使用

1. 管理员进入 **设置中心 → AI 模型**，添加一个支持图片输入的视觉分析模型、一个 **Seedance 2.0 视频模型**。协议支持 OpenAI、Anthropic、火山方舟；实际能力由服务商提供。可另外添加图片编辑与语音转写模型。
2. 进入 **设置中心 → 对象存储**，填写火山 TOS 的地域、Endpoint、Bucket、Access Key ID 和 Secret Access Key 并启用。当前视频生成必须使用 TOS，向云端模型提供可访问的参考图片和短视频。桶保持私有，对 `vio/` 前缀设置合适的生命周期（如 7 天）。
3. 在 **用户管理** 中创建成员账号。用户只能访问自己的项目，管理员可管理账号与公共模型；密钥不会返回普通用户浏览器。
4. 在 **视频复刻** 中上传一个参考视频与 1–8 张产品图，填写真实产品信息，选择模型和复刻等级。
5. 点击 **分析参考视频**。检查产品档案、各镜头的产品出现位置、可见部件、操作、缺失素材和替换策略。产品可能在背景、局部、遮挡、反射或包装中出现；一致性要求独立于复刻等级。
6. 需要补充真实角度时，在 **项目素材** 上传产品图，再重新分析。补图保留原素材并清除旧分析；开始生成后不再允许更换项目素材。也可将不适合原片操作的片段明确改为 **调整动作与构图**。保存方案不会调用模型。
7. 确认每段的 **直接生成 / 关键画面引导 / 调整动作与构图** 策略及葡语口播、字幕。关键画面引导需要创建项目时选择支持多图编辑的图片模型；系统先编辑每段一张代表关键画面并核对产品，未通过时停止该段。关键画面与改编策略均不输入原视频，可能降低动作还原程度。标为 **需补素材** 的片段不能直接生成。
8. 点击 **开始生成视频**。各段生成后自动抽帧检查产品一致性，再转码、添加字幕和拼接保存。发现问题或检查无法确定时，状态为 **待人工审核**，仍可预览、下载成片和查看问题时间点。
9. 有问题的片段可点击 **仅重做此片段**，填写修复要求并确认额外费用。每段视频生成提交最多 3 次（含首次），不会因检查不通过自动重做。其他片段保留，历史版本可预览；旧成片保留至新版本完成合成。**重新检查** 只调用视觉模型，不生成新视频。

默认值：巴西站点、平衡复刻、背景音乐/口播/字幕均开启、与参考视频同长、9:16、720P。参考视频支持 2–300 秒，单文件默认上限 200 MB，单用户累计默认上限 2 GB。视频默认同长时允许不足 4 秒的源片：生成至少 4 秒后裁剪。自定义总时长为 4–300 秒。

选择配置中的单价只用于估算，未写死模型价格。真实费用以服务商账单为准，还可能包含参考视频输入、分析、转写、修图及重试。

详见 [模型与存储配置](docs/PROVIDERS.md)、[功能设计与系统架构](docs/ARCHITECTURE.md)。

## 当前已实现及实际边界

- 管理员初始化、创建/停用用户、密码重置、会话与 CSRF 验证、用户间项目和素材隔离。
- 管理员配置模型和加密保存密钥，成员选择已启用模型；支持官方或兼容的中转站地址。
- 镜头变化检测与覆盖全片的抽帧分析、产品档案和部件约束、缺失角度提示、四档复刻等级、可编辑分镜、巴西葡语文案、可选音频转写。
- 原图保留、图片转正/透明铺白/保守缩放；配置图片模型时按分析结果编辑主图，并用视觉模型核对产品一致性，失败则保留原图。
- Seedance 异步提交/查询、私有 TOS 上传与临时链接、分段任务持久化、失败重试、停止本地任务。
- 优先沿检测到的镜头切点分段，最长 15 秒，长视频用 FFmpeg 合成；直接生成按需参考上一段抽样检查通过的有效末帧，统一 H.264/AAC、30 fps 和画面比例，准确叠加字幕。
- 每段可选择直接生成、关键画面引导或调整动作与构图；生成后检查旧产品残留、混合外观、结构变化、操作和文字，支持付费局部重做、历史版本预览与不生成视频的复查。
- 图片制作独立模块目前是后续入口；商品图优化已经在视频流程中实现。

自动测试模拟模型服务并真实运行本地视频处理；新增一致性检查和关键画面策略仍需用你的模型和实际商品样片验证效果，开发测试不会自动提交计费生成。

分析使用最多 36 张镜头变化与时间覆盖抽帧，单段结果检查最多 12 张。视觉切点不等同于精确语义镜头，抽样可能漏掉快速动作、短暂局部和字幕。检查通过仅表示抽样画面未发现问题，不保证全帧正确，也不能检查音轨；最终成片需人工完整预览。缺失的真实结构不能靠 AI 补图证明。

图片优化、关键画面编辑及其视觉核对、视频生成后的视觉检查都会增加模型费用和耗时；仅配置视频每秒单价的估算不包含这些费用。关键画面失败后可 **修改此片段策略**，保存不调用模型，再由用户主动重试。图片编辑请求状态不确定时不会自动重复提交。

“复刻音乐”目前是借鉴音乐风格和节奏重新生成；“复刻口播”是基于转写/产品事实用 pt-BR 重写，不克隆特定人的声纹。Seedance 返回混合音轨，单独关闭音乐或口播依赖模型遵循提示词；两项都关闭时最终视频会强制移除音轨。字幕按片段时间叠加，尚未逐词对齐。长视频的跨片段音色和音乐连贯性需要试听。

## 常见问题

### 分析分镜反复出现格式错误

模型把“约束”等列表字段返回成单段文字时，系统会在本地转换为单项列表；可为空的列表返回 `null` 时会转为空列表，再执行完整校验。不会因此重新分析整段视频，也不会凭空补充产品细节、镜头或时间。

每次收到分析回复后，先将原始结果保存在数据库中的项目素材，再校验。素材、项目设置和所选模型未变化时，**重试任务** 优先继续处理已保存回复；本地修复不调用模型。确需修正个别字段的格式时，最多额外调用一次文本修复，只请求错误字段，不重新发送图片或完整分析视频。修复失败后仍保留结果并显示中文原因，不因连续重试反复发起格式修复。

回复被截断、无法解析、缺失必要内容或时间线有误时，会停止并保留结果，避免把不完整分析当成成功。**重新分析素材** 会主动调用模型重新分析，产生分析费用；已有的原始回复仍保留在 **项目素材** 中，可查看或下载。旧版失败任务没有保存原始回复，首次重试仍需调用分析模型。

### 生成音频版权错误

如果出现 `OutputAudioSensitiveContentDetected.PolicyViolation`，表示供应商判定生成音频可能涉及版权限制，接口不能确认是音乐还是口播。页面现在会显示具体错误码和中文原因，而不会只显示“生成失败”。

尚无成功片段的项目可以点 **调整音频设置**，选择 **仅原创口播**（关闭配乐和参考原片音轨）或 **先生成无声版**，保存后再手动重试。原图、分镜和字幕保持不变；保存设置不调用模型，重试可能产生新的费用。原片音轨关闭后会实际从上传的参考视频中去除，不只是修改提示词。已生成成功片段或存在提交状态未确认的任务时，不允许中途改变声音配置。

错误含义参见 [火山引擎错误码文档](https://docs.volcengine.com/docs/82379/1299023)。调整内容后仍需供应商审核，不能保证通过。

## 数据、备份与迁移

图片和视频**原始二进制、衍生素材、成片、分镜、用户、任务记录都保存在数据库**；默认数据库为 `data/videoimage.db`。仅 FFmpeg 工作文件位于操作系统临时目录并在任务结束后清理。代码、启动配置、数据库文件和密钥本身当然仍需要位于文件系统。

`data/app.key` 是模型/TOS 密钥的加密主密钥，必须和数据库一起备份，单独复制数据库无法解密已有 API 配置。运行中的 SQLite 不能只随手复制 `.db` 文件；请使用一致性备份命令：

```powershell
.\.venv\Scripts\python.exe -m app.cli backup
```

恢复时停止服务，将备份中的 `videoimage.db` 与 `app.key` 放入新的数据目录，再设置 `VIO_DATA_DIR` 指向该目录后启动。不要把备份和密钥提交到 Git。

SQLAlchemy + Alembic 管理数据库结构。后续可迁移到阿里云 RDS PostgreSQL：安装 `psycopg[binary]`，在空目标库执行同版本 Alembic 迁移，再停止旧服务并运行 `app.cli migrate-data --target-url ...` 复制数据，最后切换 `DATABASE_URL`。步骤与边界见架构文档；云数据库迁移尚未实测。

本机管理员忘记密码：

```powershell
.\.venv\Scripts\python.exe -m app.cli reset-password 管理员用户名
```

密码在终端隐式输入，重置后旧会话失效。

## 检查与部署

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --check app/static/app.js
node tests/test_frontend.js
```

测试数据库创建在系统临时目录，绝不清空项目数据。测试覆盖权限/素材隔离、任务防重复提交、模型协议、媒体下载限制、图片处理、真实 FFmpeg 合成与完整模拟生成流程。

也提供 `Dockerfile` / `compose.yaml`：`docker compose up --build -d`，再从 `docker compose logs` 查看首次初始化令牌。Docker 部署文件已提供，但本机未执行容器构建。
