# 词-复刻视频（Hypit 插件）

这是可单独启用、停用和移除的视频制作模块。原有 **视频复刻** 保持独立，项目、账号、模型密钥和作品库仍由 VideoImageOperation 管理。Hypit 使用固定版本 `@hypit/hypit@0.2.17`，对应调研的上游提交 `7f730abf72fa1e4a543eed8cd1807319d9f18196`；安装清单与许可证保存在 `integrations/hypit/`。

## 服务主机安装与启用

在项目目录运行，需先有项目的 Python 虚拟环境以及 Node.js 22.15 或以上版本：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/install_hypit.py
.\.venv\Scripts\python.exe -X utf8 -m app.plugins.word_recreate.engine --status
```

安装脚本仅准备本机 Hypit 依赖和渲染环境，不调用收费模型，也不会自动重启主服务。Hypit 的依赖和运行状态与主项目 Python 环境隔离，不要求团队其他电脑安装 Node.js。运行状态保存在 `.integrations/hypit-state/`，原生视频处理临时目录在任务结束后清理。Hypit 在 `data/word-work/` 保留尚未成功合成的工作目录用于恢复，成功归档后清理该版本目录；正式素材、工作流归档、字幕对齐记录和成片保存到项目数据库。

更新主项目后由管理员安排重启，进入 **设置中心 → 词-复刻视频**，点击 **检查引擎**。只有引擎就绪才能开启 **启用词-复刻视频**，默认关闭。检查引擎不调用收费模型。开启后，侧边栏和新建项目入口显示 **词-复刻视频**。

## 创建与生成

1. 在 **AI 模型** 中配置视觉分析模型及 Seedance 或万相视频模型，并按现有流程配置 TOS。图片优化模型可选。
2. 上传参考视频、1–8 张真实产品图，填写产品事实，选择模型、复刻等级和输出规格。默认巴西站点、pt-BR、9:16、720P、参考片同长，音乐、口播、字幕开启。
3. **口播与字幕同时开启时必须选择支持逐词时间戳的音频转写模型**。可选择支持 `verbose_json` 和词级时间戳的 OpenAI 兼容模型，或阿里云百炼（音频转写）协议下的 `qwen3-asr-flash-filetrans`。阿里云文件转写需已配置 TOS，项目请求 `enable_words=true` 取得词时间；仅返回普通文字的中转接口不能用于逐词对齐。配置方法见 [阿里云音频转写](PROVIDERS.md#阿里云音频转写)。
4. 分析后确认产品档案、分镜及巴西葡语文案。保存分镜不调用模型；重新分析会产生分析费用。
5. 生成各视频片段，再识别生成结果中的实际口播，取得词级时间并由 Hypit 合成字幕与成片。超过单段长度的视频沿用分段生成、持久化任务及长视频合成。
6. 完整试听、预览商品细节及字幕后下载。启用逐词口播字幕的成片保持 **待人工审核**，产品抽帧检查通过也不会自动批准音轨和字幕。分镜文案与模型最终说出的内容可能不同，字幕时间以识别到的实际声音为准；转写也可能有识别错误，巴西葡语语言及商品卖点仍需人工验收。

**逐词高亮** 和 **普通字幕** 是字幕样式选项。关闭口播时，字幕按分镜时间显示，两种样式都不代表真实的口播逐词对齐。关闭字幕时不执行用于字幕对齐的成片转写。语音对齐所需的转写会产生额外模型费用，不能只凭配置的视频每秒单价判断总成本。

阿里云返回 `SUCCESS_WITH_NO_VALID_FRAGMENT` 时，**模型任务** 显示 **未识别到口播**。参考视频仍可按产品事实和参考画面分析、编写新口播，无法还原原口播；成片必须识别到实际口播并取得有效词时间戳才能合成口播字幕，否则任务停在 **需要处理**，保留已生成片段，不编造台词或字幕时间。该错误不能单凭名称判断原片完全无声，背景音乐、音效等声音也可能不包含可识别的口播。

## 项目权限与恢复

- 默认只看自己的项目；管理员开启团队共享后，其他人的项目只可查看和下载，制作人和管理员才可修改或提交任务。
- 作品库同时保存原生复刻和 Hypit 项目，标明 **视频复刻 / 词-复刻视频**、制作人及创建时间，可使用 **我的项目**、状态及名称筛选。
- 分析原始回复、视频片段、任务 ID、音频转写原始回复、工作流 ZIP、字幕对齐 JSON、合成记录及成片保存在数据库，项目素材中提供查看或下载。内部渲染提交凭据不显示为用户素材。已有云端任务恢复时继续查询，不因本地渲染失败自动重做已生成片段。
- 服务中断时，正在执行的词复刻任务启动后标记为 **需要处理**，由用户明确点击 **重试任务**。重试复用已保存片段和转写回复；没有确认结果的付费请求不会自动再次提交。
- 提交结果未确认时由管理员核对并关联供应商任务 ID，避免重复计费。阿里云语音转写提交未确认且未保存 ID 时，先在百炼控制台核对，再点击 **模型任务 → 关联转写任务 ID**；保存不调用模型。随后主动重试只继续查询关联的转写任务。OpenAI 转写提交未确认时仍需先核查服务商记录。
- 阿里云已保存 ID 的失败转写重试只继续查询原任务，不重复提交音频；**未识别到口播** 的明确结果缓存后直接复用，不会自动重做视频。参考音频无有效口播时继续视觉分析仍可能产生正常分析费用，成片无有效口播时反复重试不会生成词时间戳。
- 停用模块后禁止创建新项目、分析、生成和重试；历史内容仍按原权限查看和下载，正在执行的任务仍可主动停止。

首版不提供生成后的 **仅重做此片段** 和音频设置变更入口。需要改变创作设置或替换方案时，请新建测试项目。产品一致性检查仍为有限抽帧，不能保证所有局部镜头都已正确替换；Hypit 的组织和合成能力不等同于更高的商品替换准确率。

## 停用与移除

先在设置中心关闭模块，等待现有任务完成或停止它们。停用不删除项目、素材和成片。准备移除时先完成数据库和 `data/app.key` 的一致性备份，再由服务主机管理员移除 `integrations/hypit/node_modules/` 以及 `.integrations/hypit-state/` 中的引擎依赖与运行缓存。对于未成功合成且不再需要恢复的 `data/word-work/` 工作目录，可在确认没有运行任务后清理。保留主项目的插件适配代码及历史项目识别能力，可继续查看数据库中归档的作品；重新安装后可再次检查并启用。

许可证和 Hypit 标识保留在安装目录，不删除许可证文件。项目在组织内部使用；对外提供或再分发前应根据实际使用方式核对上游许可条件。
